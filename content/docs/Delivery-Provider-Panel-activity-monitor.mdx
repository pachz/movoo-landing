## Shipment

The **Shipment** page shows all shipments flowing through the delivery provider account.  
It provides filters to quickly view shipments by status:  
`All`, `Created`, `Accepted`, `Dispatched`, `Picked Up`, `In Transit`, `Delivered`, `Cancelled`, `Failed`.

Each row in the list includes:  
`Integration ID`, `Source`, `Destination`, `Shipment ID`, `Created Date`, `Status`, `COD`, `Last Updated`, `Action`.

From here you can monitor shipment lifecycles, track COD (Cash on Delivery) shipments,  
and open details for deeper investigation when needed.

---
## API Logs

The **API Logs** page provides a complete record of all API requests and responses handled through Muvx.  
It helps delivery providers monitor integrations and debug issues.

Each log entry includes:  
`Company`, `Order ID`, `API Name`, `Status Code`, `Timestamp`, `Path`, `IP Address`, `Details`.

Filters allow you to search logs by status code, API name, date range, or identifiers.  
Click **View Details** on a row to open the full request and response payload.
